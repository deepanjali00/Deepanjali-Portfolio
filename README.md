2. Content fixes

   • Title mismatch: the header says "Software Developer" while the page title and spec table say "Software Engineer". Pick one.
   • English (C2): this is a claim admissions offices and employers can verify. Unless there is a result that supports it, use "English (professional)" for now and replace it with the IELTS band once available.
   • Tumor Insight: add one line such as "Research project, not a diagnostic tool". It makes the medical claim more credible.
   • Contact block: the "Website" row links to the site the visitor is already on. Replace it with GitHub, which is currently missing from the whole page.
   • CV download: it points to cv.txt. Use a proper PDF.
   • Education: remove the details form this section i mean the descriptions remove it entirely

3. Design and structure
   • Section order: recruiters decide in about 20 seconds, so put Selected Work right after the hero, then Experience, Skills, Education and Certifications, then Contact.
   • Contrast: the second experience entry and the Education entry are dimmed so much that they are hard to read on a dark background. Raise their opacity to about 0.75–0.85.
   • Numbering: both Selected Work and Contact are labelled A-05. Make Contact A-06.
   • Skills: four equal columns of plain lists say little. Drop "HTML", "Postman" and "Agile/Scrum" as skills, and group the rest by strength (e.g. "Daily use" vs "Familiar"). That reads as more honest and more senior.
   • Blog link: if /blog has no posts yet, remove it from the nav. An empty page hurts more than no link. heres the link to blog: https://medium.com/@deepanjalinagarkoti/stop-copy-pasting-google-login-understand-oauth-passport-google-strategy-in-nestjs-e21ff5c00775
   • Project cards: add a "View code" link where the repo is public, and a "Live demo" link wherever one exists (only EarnVault has one).
   • Check before launch: that /og.jpg shows a proper preview when the link is shared on LinkedIn, and how the page looks on a phone.
